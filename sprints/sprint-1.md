## 🟢 Sprint 1 : Visiteur (Interface Publique)

**Sprint Goal:** Deliver a complete, usable public real estate website.

### User Stories

| ID | User Story                                                  | Points |
| -- | ----------------------------------------------------------- | ------ |
| V1 | As a visitor, I want to browse property listings            | 5      |
| V2 | As a visitor, I want to search & filter listings            | 8      |
| V3 | As a visitor, I want to view property details               | 5      |
| V4 | As a visitor, I want to contact the agency about a property | 3      |

### Deliverables

* Public listings page
* Search & filters (price, location, type)
* Property detail page
* Contact form per listing
* Responsive UI (Tailwind)

**DoD**

* Only **published listings** are visible
* No authentication required
* Clean UX for non-technical users
