## 🟡 Sprint 2 : Publication (Back-Office CRUD)

**Sprint Goal:** Enable internal staff to manage property listings.

### User Stories

| ID | User Story                                             | Points |
| -- | ------------------------------------------------------ | ------ |
| P1 | As an assistant, I want to create property listings    | 5      |
| P2 | As an assistant, I want to edit and delete drafts      | 5      |
| P3 | As a system, I want listing statuses (draft/published) | 3      |
| P4 | As a staff member, I want a back-office dashboard      | 3      |

### Deliverables

* Back-office CRUD (properties)
* Status management (`draft / published`)
* Assistant dashboard
* Server-side validation

**DoD**

* CRUD fully functional
* Listings not public unless published
* No admin permissions yet
